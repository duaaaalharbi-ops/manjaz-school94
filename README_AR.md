# منجز — تحديث المناوبة اليومية والتكريمات (20.0)

## القيد المعتمد
**الفسحة مخصصة للإداريات فقط في التوليد الآلي.** يتم حجز ست إداريات أولًا للفسحة، ثم توزيع ست منفذات للصباح وست لنهاية الدوام من القائمة الموحدة للمعلمات والإداريات، دون تكرار الاسم في اليوم. عند تعديل الجدول يدويًا تظل جميع الحقول قابلة للتغيير؛ قيد الفسحة يخص التوليد الآلي وفق الطلب.

## ما يتضمنه التحديث

- بطاقة «إضافة تكريم» قابلة للفتح، تستخدم نموذج التكريم والحفظ السحابي الأصلي دون نسخه أو استبدال معالجاته. أزرار تعديل/حذف التكريم المعتمد مرئية فقط بعد التحقق من جلسة الإدارة.
- «المناوبة اليومية» في الرئيسية والقائمة الجانبية؛ ٣ فترات × ٦ منفذات (١٨ تكليفًا).
- قائمة مشتركة قابلة لإضافة المعلمات والإداريات؛ لا يوجد نموذج استثناءات.
- الإنشاء اليدوي، التوليد الآلي، تعديل أي اسم، العدالة باستخدام سجل التوزيعات السابقة وتدوير الفترات بين المؤهلات.
- نشر الجدول، توليد رابط فردي لكل منفذة، «تم الاطلاع» وتوقيت التوثيق.
- إحصائيات إجمالية وبحسب الفترة، والطباعة أو الحفظ PDF من نافذة طباعة المتصفح.
- حفظ مستقل في جداول `mj_duty_*` المحمية بسياسات RLS، ولا تُغيَّر جداول الاحتياط أو المنجزات أو الشهادات.

## طريقة التطبيق (ملفات الرفع اليدوي)

### ١. إعداد قاعدة البيانات — مرة واحدة

من لوحة Supabase الخاصة بمشروع منجز، افتحي SQL Editor، وراجعي ثم نفذي محتوى الملف **`daily-duty.sql`**. لم يُنفذ هذا الملف تلقائيًا؛ لا تتغير البيانات القائمة عند فتح الحزمة أو رفع JavaScript. يتطلب إنشاء ٤ جداول و٥ وظائف وسجل صلاحيات مستخدم الإدارة.

### ٢. تحديث موقع GitHub

ملف الموقع المطلوب رفعه **`manjaz-urgent18.js`** يستبدل الملف الأصلي بالاسم نفسه، وليس نسخة باسم جديد. يضم البطاقة الجديدة وقسم المناوبة كاملًا، ولا يغيّر ملفات الاحتياط.

لمن يعمل على نسخة محلية من مستودع `duaaaalharbi-ops/manjaz-school94`، يمكن تشغيل:

```bash
python install_update.py /path/to/manjaz-school94
```

سينشئ نسخة احتياطية، ويُحدّث `manjaz-urgent18.js`، ويغيّر في `index.html` رقم إصدار استدعاء JavaScript فقط إلى `20.0-daily-duty` لمنع ظهور النسخة القديمة بسبب التخزين المؤقت. بعد ذلك ارفعي الملفين المعدلين إلى المستودع عبر GitHub أو أي أداة نشر مرخّصة.

لمن يرفع من الجوال، يمكن استبدال `manjaz-urgent18.js` مباشرة؛ لكن ينبغي تعديل رابط تحميله داخل `index.html` إلى:

`<script src="manjaz-urgent18.js?v=20.0-daily-duty"></script>`

**لا ترفعي ملف ZIP نفسه بوصفه ملف موقع؛ الملفات الموجودة داخله هي التي تُرفع.**

### ٣. فحص بعد النشر

1. في الرئيسية تظهر بطاقة «المناوبة اليومية».
2. في التكريمات تظهر بطاقة «إضافة تكريم»، ويُستخدم النموذج الأصلي نفسه.
3. افتحي «الصلاحيات الإدارية» وسجّلي الدخول، ثم افتحي المناوبة اليومية.
4. أضيفي ١٨ اسمًا على الأقل، منها **٦ إداريات على الأقل**؛ حددي اليوم واطلبي «توليد آلي عادل».
5. تأكدي من أن مناوِبات الفسحة الست إداريات، وأن ١٨ اسمًا مختلفة.
6. جرّبي تغيير اسم واحد وحفظه ثم النشر، وارسلي رابطًا تجريبيًا إلى صاحبة التكليف لتجربة «تم الاطلاع».

## اختبار / حدود

اجتازت الشيفرة `node --check` واختبار متصفح محلي بمحاكاة ردود قاعدة البيانات على الجوال (١٨ خانة، قيد الإداريات، حفظ التعديل، ١٨ رابطًا فرديًا، تأكيد الاطلاع، وتوسعة إضافة تكريم). **لم تُختبر عمليات قاعدة البيانات الحقيقية أو النشر الفعلي**. لم يُعدل أي سجل قائم في Supabase. يُنصح بالتجربة على بيانات غير حقيقية قبل نشر الجدول المدرسي.

### ملاحظة تخص العدالة

لأن الإداريات وحدهن مؤهلات للفسحة، فهن يتحملن تكليفات هذه الفترة أكثر من المعلمات بالضرورة. تُستخدم أعداد التكليفات التاريخية وتوزيع الفترات لزيادة التوازن داخل القيود المتاحة؛ لا يمكن تحقيق تساوٍ كامل بين فئتين تختلفان في الأهلية لكل فترة.
