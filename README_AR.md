# منجز — تحديث المناوبة اليومية 23.0 (الدخول الإداري وقائمة المنفذات)

**الحزمة تحتوي على ملف JavaScript كامل لاستبدال الملف الأصلي، وليست إضافة جديدة فوق ملف قديم.**

## ما عولج

1. زر «دخول الإدارة» داخل قسم «المناوبة اليومية» لم يعد يحوّل إلى `#admin-permissions`.
2. إن لم يكن الحساب مسجلًا، يظهر نموذج تسجيل الدخول الإداري داخل بطاقة المناوبة نفسها، مع التحقق من الحساب في Supabase.
3. بعد الدخول تظهر بطاقات الإنشاء اليدوي والآلي واحتساب المفاضلة داخل المناوبة، بنفس واجهة قسم الاحتياط.
4. القوائم المنسدلة في خانات الصباح والفسحة ونهاية الدوام تُقسم إلى «المعلمات» (٣٩) ثم «الإداريات» (١٧)، ولكل قسم فاصل وعنوان؛ مع أسماء مرتبة أبجديًا، في القائمة نفسها.
5. لا استثناءات للمنفذات في قسم المناوبة؛ الفسحة مخصصة للإداريات فقط **عند التوليد الآلي**، ولا تمنع القوائم التعديل اليدوي.
6. بقية وظائف التاريخ الهجري والتوليد والحفظ والنشر والطباعة والاطلاع والتكريمات محفوظة من المصدر الأصلي.

**الخطوة ٢:** افتح `index.html`، السطر **496** (أو ابحث عن النص التالي):


واستبدله بهذا السطر:

ثم احفظ التغيير (Commit changes). لا تغيّر شارة «الإصدار الثالث» في أسفل الموقع.

### قاعدة البيانات

تمت إضافة أسماء **٣٩ معلمة + ١٧ إدارية = ٥٦ منفذة** بالفعل إلى مشروع Supabase الفعلي، والتحقق من العددين. لا يُشغّل أي SQL إضافي، ولا يتطلب هذا التحديث تغيير جداول الاحتياط.

### الفحص بعد النشر

- افتح «المناوبة اليومية»، ثم «دخول الإدارة» دون تسجيل دخول: تظهر استمارة داخل القسم، ولا ينتقل الرابط إلى `#admin-permissions`.
- سجل الدخول بالإيميل وكلمة المرور الإدارية المعتادة.
- في بطاقة الإنشاء اليدوي، افتح أي قائمة للأسماء: ستظهر مجموعة «المعلمات» فوق مجموعة «الإداريات».
- تحقق من وجود ٣٩ اسمًا للمعلمات و١٧ للإداريات، ومن ظهور نفس التنسيق في الإنشاء الآلي.
- احفظ جدول اختبار واعرض «جدول النشر» ثم تأكد من إمكان الطباعة.

## ملاحظة تحقق أساسية

اختُبرت واجهة تسجيل الدخول **بخدمة Supabase مُحاكاة في المتصفح**؛ لم تُستخدم كلمة مرور الحساب الإداري الحقيقي. كما اختُبرت بقية وظائف الواجهة محليًا على Chromium، ولم يُختبر التحديث على الموقع المنشور حتى الآن بسبب رفض صلاحية الكتابة في اتصال GitHub.
