# منجز — إصلاح المناوبة اليومية (حزمة 26.0)

هذه حزمة **استبدال ملف واجهة واحد**، وليست نسخة موقع كاملة. جرى اختبارها محليًا؛ ولم تُنشر تلقائيًا.

## طريقة الرفع اليدوي

1. افتحي صفحة تعديل الملف الأصلي في GitHub:
   https://github.com/duaaaalharbi-ops/manjaz-school94/edit/main/manjaz-urgent18.js
2. استبدلي **كل محتوى الملف** بمحتوى الملف المرفق `manjaz-urgent18.js`. لا تضعيه بجانب الكود القديم ولا تضيفيه نهاية الملف؛ لأنه بديل كامل يحافظ على الوظائف السابقة.
3. اضغطي **Commit changes**.
4. افتحي ملف `index.html`:
   https://github.com/duaaaalharbi-ops/manjaz-school94/edit/main/index.html
5. في السطر الذي يستدعي `manjaz-urgent18.js` (كان السطر 496 عند الفحص)، ضعي حرفيًا:
   `<script src="manjaz-urgent18.js?v=26.0-duty-ack-a4"></script>`
   اتركي بقية الملف دون تغيير، ومنه شارة **«الإصدار الثالث»**.
6. اضغطي **Commit changes**، ثم افتحي الموقع بعد اكتمال نشر GitHub Pages.

## آلية اطلاع المستخدمات

- تحفظ الإدارة جدول يوم المناوبة وتنشره من بطاقة **نشر جدول اليوم**.
- داخل إدارة المناوبة يظهر لكل منفذة رابط مستقل، مع أزرار «نسخ الرابط»، «فتح نموذج الاطلاع»، «إرسال عبر واتساب».
- تستقبل المنفذة رابطها الخاص، وتفتحه دون تسجيل دخول إداري؛ يظهر لها اسمها والفترة المكلفة بها وزر **«تأكيد الاطلاع»**.
- بعد الضغط، يسجّل النظام وقت الاطلاع ويعيد قراءة قاعدة البيانات للتحقق منه. يظهر «تم تأكيد الاطلاع»، ولا يقبل الضغط المتكرر.
- تعرض صفحة جدول المناوبة حالة كل منفذة ووقت اطلاعها، ويمكن تحديث الحالة فورًا بزر «تحديث حالات الاطلاع». تتحدث أيضًا عند العودة للصفحة ودوريًا، دون حذف التعديلات اليدوية المفتوحة.
- لا يتضمن الجدول العام رموز التأكيد السرية؛ يجب إرسال الرابط الشخصي من الإدارة إلى المنفذة الصحيحة.

## جدول النشر والطباعة

- ثلاثة جداول مستقلة للصباح والفسحة ونهاية الدوام، مع عناوين يمينية ومسافات مناسبة ولون مميز لأول صف.
- العدد ديناميكي (١ إلى ٦ أسماء في كل فترة)، ويظهر عمود **حالة الاطلاع** وملخص «تم الاطلاع».
- معاينة مستخدمة متجاوبة مع الجوال وزر «تكبير المعاينة»، ويتم تجديد بيانات الاطلاع عند فتح المعاينة.
- يفتح زر **طباعة الجدول** المعاينة أولًا؛ اضغطي بداخلها **«طباعة / حفظ PDF»** لضمان دعم Safari على الآيفون، حيث قد يمنع طباعة تُستدعى بعد تحميل غير متزامن.
- قالب الطباعة مستقل عن جسم الموقع وشريط التنقل. اختُبر حتى ١٨ تكليفًا على صفحة A4 واحدة في Chromium. سلوك الطباعة على Safari والبيانات الحقيقية يُتحقّق منه بعد النشر.
