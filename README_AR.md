# تحديث منجز — المناوبة اليومية 27.0

## ما تم تنفيذه

- رابط واتساب عام واحد يفتح جدول المناوبة اليومية، مع أزرار «تأكيد الاطلاع» في صف كل منفذة، دون رمز أو تسجيل دخول.
- رسالة واتساب واحدة تتضمن رابط جدول المناوبة العام لتأكيد الاطلاع، ورابط جدول النشر الرسمي للعرض والطباعة، ويتغير التاريخ تلقائيًا حسب اليوم المختار.
- بعد ضغط «تأكيد الاطلاع» يظهر وقت التأكيد، وتُحدث الحالة من قاعدة البيانات في الجدول العام وفي معاينة النشر.
- ثلاثة جداول نشر مستقلة: المناوبة الصباحية، مناوبة الفسحة، ومناوبة نهاية الدوام؛ عنوان كل جدول جهة اليمين، مع عمود «حالة الاطلاع» قبل «التوقيع».
- صفوف الأسماء جميعها بيضاء دون لون مميز للصف الأول.
- المعاينة ملائمة للجوال، والطباعة على ورقة A4 واحدة في اختبار 18 تكليفًا.
- إخفاء أدوات إرسال الروابط الفردية من لوحة الإدارة؛ لم تُحذف أي روابط مخزنة أو وظائف سابقة، حفاظًا على التوافق.
- بقاء مزامنة التاريخ والحفظ والإنشاء اليدوي والآلي والإحصائيات.

## خطوات الرفع إلى GitHub

1. افتحي ملف `manjaz-urgent18.js` الموجود في هذه الحزمة، واستبدلي به الملف الذي يحمل الاسم نفسه في **جذر المستودع** `duaaaalharbi-ops/manjaz-school94`.
2. افتحي ملف `index.html` في GitHub، وابحثي عن السطر الذي يحتوي على `manjaz-urgent18.js?v=` (كان سابقًا بالقرب من السطر 496).
3. استبدلي **استدعاء الملف وحده** بالسطر:

   `<script src="manjaz-urgent18.js?v=27.0-public-duty-ack"></script>`

4. احفظي التعديل عبر **Commit changes**، ثم افتحي الموقع مرة أخرى بعد اكتمال نشر GitHub Pages.
5. في المناوبة اليومية: احفظي الجدول ثم انشريه، ثم اختاري **مشاركة عبر واتساب**. سترسل الرسالة رابط الاطلاع العام ورابط النشر الرسمي.

**تنبيه:** جرى تحديث قاعدة البيانات المتصلة بمنجز بالفعل. لا تنفذي SQL إضافيًا، ولا تغيري اسم النسخة المعروضة للمستخدمات «الإصدار الثالث».

## حدود التأكيد العام المؤقت

لا يتحقق الرابط العام من هوية من تضغط زر التأكيد. يمكن لأي شخص يمتلك الرابط تأكيد اطلاع منفذة أخرى؛ هذا تنفيذ مؤقت وفق طلب الإدارة لحين إضافة طريقة تحقق لاحقًا. سجلات المنفذات الحقيقية لم تُعدّل خلال اختبار الحزمة.

## النشر والتحقق

ملف المنصة المرفق مُختبر **محليًا** ولم يُرفع تلقائيًا إلى GitHub. يلزم رفع الملف وتحديث `index.html` يدويًا، ثم فحص السلوك على الرابط الفعلي.
