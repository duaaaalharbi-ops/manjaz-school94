# منجز | تعديل بطاقة المنجزات والاعتمادات — الإصدار 19.3

## المنفذ

### 1. قسم المنجزات
- إزالة بطاقة «البحث والتصفية والإحصاءات» من واجهة القسم، وإزالتها من DOM **بعد** ربط وعرض المنجزات بواسطة الكود الأصلي. لا تُحذف المنجزات ولا يتغير التخزين.
- تبقى بطاقة «إضافة منجز» متاحة وتستخدم نموذجها ومعالج الحفظ ورفع المرفقات الأصليين.
- تبقى بطاقات المنجزات المعتمدة معروضة.

### 2. قسم الإدارة | طلبات الاعتماد
- استبدال النص الأصلي «طلبات اعتماد المنجزات» بالنص «طلبات الاعتماد» في مصدر القالب `manjaz-task15.js` وفي واجهة الصفحة (حماية في حال اختلاف ذاكرة التخزين المؤقت).
- تنظيم محتوى البطاقة في **قوائم قابلة للفتح والإغلاق**: (أ) المنجزات والشراكات؛ (ب) التكريمات؛ (ج) الإنتاج المعرفي.
- عرض عدد الطلبات بجانب عنوان كل قائمة؛ والقائمة الأولى مفتوحة افتراضيًا.
- توحيد خلفيات القوائم، الحدود، المسافات، محاذاة العربية، الأزرار، الحقول، والقوائم المنسدلة؛ ارتفاع الحقول **46px** والأزرار **44px** على الأقل؛ وتهيئة العرض للجوال.
- **عدم تغيير** معالجات الاعتماد والمشاهدة والتعديل والحذف للسجلات؛ تم نقل عقد DOM المحتوية على المستمعين الأصليين بدل إعادة إنشاء أزرار الإجراءات.
- الإنتاج المعرفي لا يُقرأ ولا يُعتمد إلا بواسطة آلية الصلاحية الإدارية الموجودة أصلًا.

## طريقة التطبيق

على نسخة منفصلة من مجلد موقع «منجز»، ضعي الملفات الثلاثة الأولى بجانب بعضها وشغّلي:

```bash
python apply_manjaz_part2.py /path/to/manjaz-school94
```

يأخذ البرنامج نسخة احتياطية من `index.html` و`manjaz-task15.js` وملفي الإضافة القديمين إن وجدا؛ بعدها يحدّث ربط ملفات CSS وJS ويوحد الاسم في قالب الإدارة. يدعم التثبيت الجديد والترقية من **19.2**. يمكن التراجع باستعادة الملفات من `backup_before_part2_19_3_*`.

**حالة النشر:** أُجريت اختبارات تركيب وواجهات محلية. لم يُرفع إلى المستودع GitHub ولم يُختبر في موقع الإنتاج، لأن اتصال GitHub الممنوح سبق أن رفض الكتابة بخطأ 403. يجب اختبار التشغيل على نسخة معاينة قبل اعتماد الإنتاج.

**قيد سابق لا يتغير هنا:** قاعدة `public.records` في Supabase تحتوي صلاحيات `anon` واسعة للتعديل والحذف؛ هذه الحزمة لا تتعامل مع سياسات قاعدة البيانات لتجنب تغيير عمليات الموقع القائمة، لكنها تتطلب مراجعة أمنية مستقلة.
