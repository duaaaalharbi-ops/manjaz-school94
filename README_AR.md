# منجز — حزمة الإصلاح المباشر 19.4

**هذه حزمة تعديل للملفات الأصلية، وليست موقعًا منشورًا.** فشل اتصال GitHub المسمى «منجز» في إنشاء فرع أو رفع ملف بالخطأ `403 Resource not accessible by integration`. تنزيل الحزمة لا يغيّر الموقع تلقائيًا.

## إصلاحات الواجهة

1. **المنجزات:** تُزال بطاقة «البحث والتصفية والإحصاءات» من قالب `index.html`؛ تُحفظ المدخلات والإحصاءات داخليًا في عنصر مخفي لكي يستمر `wireAchievements` في العمل دون تغيير عمليات العرض/الحفظ. تبقى بطاقة «إضافة منجز» قابلة للتوسيع.
2. **الإدارة:** تغيير عنوان البطاقة من «طلبات اعتماد المنجزات» إلى **«طلبات الاعتماد»** في مصدر `manjaz-task15.js`. تنسيق داخلي متجانس عبر ثلاث بطاقات قابلة للفتح لطلبات المنجزات والشراكات، والتكريمات، والإنتاج المعرفي. الإبقاء على المستمعات الأصلية لأزرار الاعتماد والتعديل والحذف، ومسار الإنتاج المعرفي المحمي الموجود في Supabase.
3. **التكريمات:** يغلف القالب **نموذج `awardForm` الأصلي نفسه** داخل بطاقة «إضافة تكريم» قابلة للتوسيع، فلا تنشأ نسخة مكررة ولا يُستبدل معالج الحفظ السحابي. الإبقاء على مشاهدة التفاصيل، وإظهار أزرار التعديل والحذف عند التحقق من جلسة حساب الإدارة في Supabase. أزيل التعطيل البرمجي القديم لهذه الأزرار من `manjaz-urgent18.js`.
4. تسوية ألوان وحدود وأحجام الحقول ومراعاة التصميم المتجاوب والعربية RTL.

## تطبيق على نسخة المستودع (للمسؤول التقني)

1. استخرج الحزمة بجوار **نسخة محلية مطابقة للمستودع** `duaaaalharbi-ops/manjaz-school94` وتأكد أن `index.html` و`manjaz-task15.js` و`manjaz-urgent18.js` داخلها.
2. شغّل (الاستبدال في مجلد المستودع الصحيح):

   `python install_manjaz_19_4.py /path/to/manjaz-school94`

3. يُنشئ المُثبّت مجلدًا احتياطيًا قبل التغيير، ويفحص علامات القوالب قبل الكتابة، ثم يحدّث الملفات: `index.html` و`manjaz-task15.js` و`manjaz-urgent18.js` ويضيف/يحدّث `manjaz-part2.js` و`manjaz-part2.css`.
4. نفّذ اختبارات المشروع الكاملة، ثم **ارفع الملفات الخمسة للمستودع عن طريق حساب لديه صلاحية كتابة Contents**، وانتظر اكتمال النشر المرتبط بالمستودع. عند استخدام GitHub Pages تحقق من الفرع ومجلد النشر الصحيحين.
5. في الموقع المنشور، راجع على الكمبيوتر والجوال `#achievements` و`#admin` و`#awards`. سجّل الدخول من قسم «الصلاحيات الإدارية» لإظهار إدارة التكريمات. لا تختبر الحذف على بيانات حقيقية؛ استخدم سجلًا اختباريًا جديدًا فقط.

## عدم تغيير البيانات والوظائف

- لا توجد ملفات SQL أو عمليات كتابة على Supabase في هذه الحزمة.
- لم يتغير كود `app.js` أو `awards-cloud.js` أو `admin-permissions.js`، ولم يتغير تصميم الشهادات أو ملفات الاحتياط.
- عناصر التقاط البيانات الأصلية ومعالجات الإدخال والاعتماد لا يعاد إنشاؤها.
- يحدد المُثبّت نسخة احتياطية ويوقف العمل إذا تعذّر العثور على علامات المصدر المتوقعة.

## ملاحظة أمنية

معاينة صلاحيات جدول `public.records` في Supabase أظهرت سياسات قد تسمح بالتعديل/الحذف المجهول لبعض السجلات. إظهار أزرار التعديل والحذف للإدارة في الواجهة **ليس بديلًا عن أمان قاعدة البيانات**؛ يلزم تدقيق RLS قبل اعتبار النظام محميًا من تعديل غير المخوّلين. لم تُغيّر هذه الحزمة السياسات حتى لا تُعطّل الوظائف القائمة دون اختبار تكاملي.
