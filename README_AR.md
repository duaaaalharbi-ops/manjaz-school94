# منجز 22.0 — إصلاح التاريخ الهجري والمزامنة التلقائية للمناوبة

## سبب ظهور الخطأ في الصورة

- **مستطيل التاريخ:** كان يعتمد على حقل تاريخ أصلي بالميلادي وتجاوز حدود البطاقة على الآيفون. أصبح زر اختيار **هجري أم القرى فقط**؛ مع حفظ ISO في الخلفية للتوافق مع PostgreSQL، دون إظهار الميلادي.
- **رسالة الخطأ `mj_duty_public_stats`:** فحص قاعدة Supabase الحالية أظهر عدم وجود دوال `mj_duty_public_stats` و`mj_duty_public_day`، وعدم وجود جداول `mj_duty_*`. يلزم تنفيذ `daily-duty.sql` في قاعدة «منجز».
- **المزامنة:** عند تغيير التاريخ تتحدث تلقائيًا بيانات الجدول، المنفذات، القوائم المنسدلة، الإحصائيات، حالة النشر والاطلاع، الروابط الفردية ومعاينة الطباعة. تُمنع الاستجابات المتأخرة من اليوم السابق من استبدال يوم جديد.

## خطوات الرفع اليدوي

1. افتحي مستودع GitHub: `duaaaalharbi-ops/manjaz-school94`.
2. استبدلي ملف **`manjaz-urgent18.js`** الموجود في جذر المستودع بالملف الذي يحمل الاسم نفسه داخل هذه الحزمة. الملف يضمّ الإصلاحات وبطاقة إضافة التكريم السابقة. **لا تعدلي `daily-reserve.js`.**
3. في `index.html` غيّري **قيمة `v=` فقط** في رابط `manjaz-urgent18.js` ليصبح:
   `manjaz-urgent18.js?v=22.0-hijri-sync`
4. في **Supabase** لمشروع **Manjaz School 94**، افتحي **SQL Editor** ونفذي ملف **`daily-duty.sql`** إذا كانت جداول المناوبة غير مثبتة، كما أظهر فحص قاعدة البيانات. **لا تنفذيه في مشروع وصال**. يقوم الملف بإنشاء جداول ودوال مستقلة عن الاحتياط، وإدراج 17 اسمًا إداريًا دون تكرار.
5. انتظري نشر GitHub Pages، ثم أعيدي فتح الموقع. إذا ظهرت واجهة قديمة، حدّثي الصفحة لتجاوز التخزين المؤقت.

**للتثبيت من مجلد كامل على جهازك:** يمكن تشغيل `python install_update.py <مجلد-الموقع>`؛ يصنع البرنامج نسخة احتياطية للملفين قبل التعديل. لا يرفع الملف تلقائيًا إلى GitHub.

## عناصر المزامنة التلقائية

| العنصر | السلوك بعد تغيير التاريخ |
|---|---|
| العنوان والتاريخ | هجري أم القرى فقط |
| الجدول العام | يعرض المنشور للتاريخ المحدد فقط |
| الإنشاء اليدوي والآلي | يحمل تكليفات التاريخ الجديد مع الاحتفاظ بقائمة المنفذات |
| الروابط وحالة الاطلاع | رابط وحالة كل منفذة للتاريخ المحدد |
| الإحصائيات والمفاضلة | بحسب التاريخ والشهر الهجري المختارين |
| الطباعة وجدول النشر | يستخدمان صفوف اليوم الجديد المعتمدة فقط |
| التعديلات غير المحفوظة | يظهر تحذير قبل الانتقال بتاريخ آخر |

عند تعطل إحصائيات Supabase يستمر تحميل جدول اليوم بصورة مستقلة، وتظهر رسالة تفسيرية في بطاقة الإحصائيات.

## ضوابط لم تتغير

- الفسحة للإداريات فقط **عند التوليد الآلي**.
- الحد الأقصى 6 منفذات لكل فترة، مع حفظ 1–6 لكل فترة دون صفوف فارغة.
- تدوير عادل وعدم تكرار المنفذة في اليوم نفسه عند التوليد الآلي.
- لا توجد لوحة تميز.
- لا تغيير في ملفات أو قاعدة بيانات الاحتياط.

## حدود الاختبار

اجتازت الحزمة اختبارات JavaScript ومحاكاة الجوال، التقويم الهجري، التبديل السريع للتواريخ، توافق الصفوف والإحصائيات والروابط والطباعة، والتعامل مع غياب دالة الإحصائيات. **لم يُنفذ SQL في قاعدة الإنتاج ولم يُنشر ملف الواجهة؛ يلزم إتمام الخطوات أعلاه.**
