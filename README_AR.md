# تحديث الاحتياط الآلي 29.0

تم تحديث قاعدة بيانات منجز بحيث ترفض التكليف الآلي الجديد المخالف.
لتظهر التصفية الصحيحة في واجهة التوليد، افتحي prepare_v29.html واصنعي الحزمة الناتجة ثم ارفعي الملفات الثلاثة:
1. daily-reserve.js
2. home-v3.js
3. index.html

يمكنك استخدام زر تجهيز التحديث عبر الإنترنت داخل الأداة. عند تعذر تحميل الملفات من GitHub، حمّلي الملفات الأصلية الثلاثة إلى جهازك وحدديها داخل الأداة.

الضوابط:
- عند إيقاف الكادر الكامل: يستبعد النصاب 20 فأكثر والأسماء المحددة بلا أي استثناء مرتبط بعدد الحصص.
- عند تفعيل الكادر الكامل: يسمح بتوسعة قائمة المعلمات؛ لا يُسمح بالغياب أو التعارض أو ساعة الرضاعة أو التتابع مع الحصة الأصلية.
- المرشدات ومحضرة المختبر للإنشاء اليدوي فقط.
- المفاضلة من الأسبوع الحالي فقط؛ إذا لا توجد مرشحة يبقى التكليف غير مُسند، ولا يُعتمد حتى يُعالج.
- البيانات المنشورة سابقًا لا تتغير.

النسخة المثبتة على GitHub كانت قديمة عند آخر فحص. حفظ قاعدة البيانات وحده لا يحل واجهة توليد المرشحات.
