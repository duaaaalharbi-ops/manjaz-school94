# منجز | المناوبة اليومية 21.0 — نسخة الرفع اليدوي

**هذه الحزمة تحتوي على تعديل برمجي فعلي، لكنها ليست منشورة تلقائيًا على موقع المدرسة.** لا ترفعي ملف ZIP مباشرة إلى GitHub بوصفه موقعًا؛ افتحيه واستخدمي الملفات المذكورة.

## وظائف النسخة

- بطاقة «المناوبة اليومية» في الرئيسية بنفس عناصر وفئات CSS المستخدمة في بطاقة «الاحتياط اليومي» (`manjaz-home-card` و`manjaz-home-actions`). لا توجد بطاقة منفصلة مختلفة الشكل.
- واجهة الإدارة والعرض العام بنفس تنظيم الاحتياط: «عرض المناوبة»، «طباعة الجدول»، «جدول النشر»، «دخول الإدارة»، وجدول وإحصائيات داخل بطاقات منسدلة، وإنشاء يدوي وآلي ومفاضلة؛ **بدون التميز**.
- ثلاث فترات؛ الحد الأقصى ست منفذات لكل فترة، والحد الأدنى منفذة واحدة في كل فترة. الحفظ والنشر متاحان بأقل من ست، ولا تظهر صفوف فارغة في جدول النشر.
- التوليد الآلي يُخصص الفسحة للإداريات فقط. يُستهدف ٦ لكل فترة مع توزيع عادل وتدوير، ويخفض العدد تلقائيًا عند نقص المنفذات دون تكرار المكلفة في اليوم.
- التعديل اليدوي لكل خانة، والحفظ وإعادة النشر، والروابط الفردية وتأكيد «تم الاطلاع» والإحصائيات اليومية والأسبوعية والشهرية الهجرية والتراكمية.
- جدول نشر رسمي A4 فيه اليوم والتاريخ الميلادي والهجري، الاسم، الفترة، حالة الاطلاع والتوقيع. «طباعة / حفظ PDF» من نافذة الطباعة؛ عدد الصفوف ديناميكي.
- استيراد **١٧ إدارية** من «الإداري.xlsx» عبر SQL مع منع التكرار. لم تُدمج أرقام المستخدمين في نور، وإنما الأسماء فقط.
- الحفاظ على بطاقة «إضافة تكريم» القابلة للتوسع والوظائف السحابية الأصلية للتكريم؛ لا تغييرات في قسم الاحتياط.

## طريقة التنفيذ اليدوي عبر GitHub + Supabase

### أولًا — SQL (قاعدة المناوبة)

1. افتحي Supabase Dashboard لمشروع «منجز» ثم SQL Editor.
2. افتحي ملف `daily-duty.sql` وراجعيه ثم انسخي محتواه ونفذيه مرة واحدة. ينشئ جداول المناوبة المستقلة ودوالها الآمنة، ويُدخل ١٧ اسمًا. **لا يمس جداول الاحتياط.**
3. تأكدي من ظهور ١٧ إدارية في `public.mj_duty_people`. لا تظهر الأسماء في الموقع قبل تنفيذ SQL.

> عند فحص المشروع في 17 أكتوبر 2026 لم تكن جداول `mj_duty_*` موجودة؛ لذلك صُمم الملف لإنشائها من الصفر. إذا نُفذ إصدار سابق من SQL في بيئة أخرى، راجعي التغييرات قبل إعادة التنفيذ. لا تُستخدمي ملف SQL الخاص بالإصدار 20.1 بعد هذا الملف.

### ثانيًا — رفع ملفات الموقع

**طريقة الجوال (ملف واحد + تعديل سطر):**

1. في مستودع `duaaaalharbi-ops/manjaz-school94` افتحي الملف **`manjaz-urgent18.js`**، واختاري تعديل/رفع النسخة الموجودة واستبدلي محتواه بالكامل بمحتوى الملف المطابق المرفق في الحزمة. لا تضيفي ملفًا باسم مختلف.
2. افتحي `index.html` وغيّري سطر تحميل `manjaz-urgent18.js` **فقط** ليصبح:

```html
<script src="manjaz-urgent18.js?v=21.0-reserve-pattern"></script>
```

3. احفظي/Commit التغييرين على الفرع المنشور؛ انتظري اكتمال النشر التلقائي من GitHub Pages أو مزود الاستضافة المستخدم، ثم أعيدي فتح الموقع بصفحة محدثة.

**طريقة الحاسب:** حمّلي المستودع أو افتحي نسخته المحلية وشغلي:

```bash
python install_update.py /PATH/TO/manjaz-school94
```

سيفحص الملفين وينشئ نسخة احتياطية من الأصل قبل أي استبدال، ويحدّث رابط التحميل في HTML. بعد ذلك ارفعي فقط `index.html` و`manjaz-urgent18.js`.

### ثالثًا — التحقق بعد النشر

1. الرئيسية: بطاقة «المناوبة اليومية» بنفس ألوان وأبعاد بطاقات الرئيسية الأخرى.
2. المناوبة: جدول اليوم، الإحصائيات، الطباعة وجدول النشر، ثم دخول الإدارة.
3. الإدارة: إنشاء يدوي وآلي واحتساب المفاضلة **دون لوحة التميز**.
4. المنفذات: وجود **١٧ إدارية** بالاسم الصحيح. أضيفي المعلمات من لوحة الإدارة عندما تتوفر قائمتهن المعتمدة.
5. ولّدي آليًا: ينبغي أن تقتصر الفسحة على الإداريات. عند ١٧ إدارية فقط قد يُولَّد جدول من ١٧ تكليفًا (٦ فسحة و٦ صباح و٥ نهاية).
6. اختاري يدويًا ٤ للصباح و٦ للفسحة و٣ للنهاية، احفظي ثم انشري: يجب ظهور **١٣ صفًا فقط** في معاينة جدول النشر.
7. افتحي الرابط الشخصي وجرّبي «تأكيد الاطلاع» ثم تحققي من تحديث الحالة.

## الأمان والاسترجاع

- قاعدة المناوبة منفصلة عن قاعدة الاحتياط (`mj_duty_*`). تتطلب أدوات الإدارة جلسة حساب الإدارة، وتتحقق الدوال من الصلاحية داخل الخادم.
- الرابط الفردي يتيح اطلاع صاحبة الرابط على بيانات تكليفها فقط؛ يجب عدم نشره في مواقع عامة.
- أزرار التنزيل المباشر PDF غير موجودة؛ استخدمي وظيفة الطباعة في الجهاز ثم «حفظ كـ PDF».
- عند حدوث مشكلة في الواجهة، أعيدي `index.html` و`manjaz-urgent18.js` من نسخة الاحتياط؛ **لا تحذفي جداول المناوبة** لأن هذا قد يؤدي إلى فقد سجلاتها.

## حدود الاختبار

اجتاز التحديث تدقيق صيغة JavaScript ومحاكاة متصفح محلية للجوال؛ **لم يُختبر تسجيل دخول حقيقي أو تنفيذ SQL على Supabase الفعلي أو النشر على الموقع**. لا تعتبر الحزمة مطبقة حتى تُنفذ الخطوتان وتُختبر عملية الحفظ الحقيقية.
