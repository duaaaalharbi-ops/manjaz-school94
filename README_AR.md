# منصة «منجز» — تعديل جدول نشر المناوبة 24.0

## نطاق التعديل

تم **تعديل جدول النشر والطباعة فقط**، مع الاحتفاظ بقية وظائف النسخة السابقة كما هي.

- جدول مستقل بعنوان **«جدول المناوبة الصباحية»**، وعنوانه محاذى لليمين مباشرة فوق الجدول.
- جدول مستقل بعنوان **«جدول مناوبة الفسحة»**، بعد مسافة رأسية واضحة.
- جدول مستقل بعنوان **«جدول مناوبة نهاية الدوام»**، بعد مسافة رأسية واضحة.
- أربعة أعمدة لكل جدول: **م، اسم المنفذة، حالة الاطلاع، التوقيع**.
- **لا تستخدم علامات الشرطة أو الشرطة السفلية في صفوف النشر** بدلًا من تكرار فترة المناوبة. لكل فترة جدولها الخاص.
- أول **صف بيانات** داخل **كل جدول** بخلفية تركواز فاتحة، مع الحفاظ على تباين الطباعة.
- لا توجد صفوف فارغة مُضافة للوصول إلى ٦؛ العدد المعروض يساوي عدد التكليفات الفعلية.
- معاينة جدول النشر و«طباعة / حفظ PDF» تستخدمان القالب ذاته.
- لم يتغير نص شارة الإصدار في أسفل الموقع: **«الإصدار الثالث»**.

## الرفع اليدوي إلى GitHub

**الملف الوحيد المطلوب استبداله:** `manjaz-urgent18.js` (ملف كامل، وليس إضافة تلحق بالملف القديم).

1. افتحي مستودع `duaaaalharbi-ops/manjaz-school94` في GitHub.
2. افتحي `manjaz-urgent18.js` واستبدلي **كل المحتوى** بمحتوى الملف المرفق بنفس الاسم؛ ثم اختاري **Commit changes**.
3. افتحي `index.html` وابحثي عن سطر تحميل `manjaz-urgent18.js` (كان في السطر 496 في آخر مراجعة). ضعي بدل سطر التحميل الموجود:

```html
<script src="manjaz-urgent18.js?v=24.0-three-duty-tables"></script>
```

4. احفظي التعديل (**Commit changes**)، ثم افتحي الموقع في تبويب جديد وانتظري اكتمال نشر GitHub Pages.
5. اختاري «المناوبة اليومية» ثم «جدول النشر»، وتحققي من العناوين الثلاثة والمحاذاة والمسافات ولون الصف الأول داخل كل جدول.
6. جرّبي «طباعة / حفظ PDF» لمعرفة عدد الصفوف الفعلي وتنسيق الطباعة.

**مهم:** لا تغيّري `daily-reserve.js`، أو ملفات الاحتياط، أو Supabase بسبب هذا التعديل؛ لا توجد تغييرات في قاعدة البيانات.

## الاختبار

- اجتاز JavaScript فحص الصياغة `node --check`.
- اجتازت محاكاة Chromium على عرض الكمبيوتر والجوال مثال 4+2+1 منفذات، دون صفوف فارغة، مع 3 جداول مستقلة وألوان صحيحة.
- تم التحقق من نمط الطباعة عبر CSS print في متصفح الاختبار.
- **الاختبار محلي ببيانات محاكاة**؛ لم يتأكد بعد ظهور التغيير على الموقع المنشور، ويلزم الرفع اليدوي واختباره عليه.
