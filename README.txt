منجز — تحديث «جدول النشر»: عنوان التفعيل وحالتا الاطلاع والتفعيل

محتوى جدول النشر النهائي لليوم (من اليمين لليسار):
1. المعلمة الغائبة
2. الحصة
3. الفصل
4. المعلمة المسند لها الاحتياط
5. عنوان التفعيل — يظهر فقط إذا أدخلته المعلمة؛ وإلا شرطة.
6. حالة الاطلاع — أخضر «تم الاطلاع» إذا كانت ackAt مسجلة، وأحمر «لم يتم الاطلاع» خلاف ذلك.
7. حالة التفعيل — «تم التفعيل» عند وجود عنوان التفعيل، وإلا «لم يتم التفعيل».
8. التوقيع — آخر عمود، فارغ للتوقيع.

الحفاظ على لون موحد لكل رقم حصة (1 إلى 7) وكامل الصف.
المعاينة ونسخة PDF: A4 أفقي لاستيعاب الأعمدة الثمانية بخط واضح.
تظل سجلات النشر الموحدة للتكليفات اليدوية والآلية كما هي؛ لا تغييرات على Supabase أو الشهادات أو ضوابط الاحتياط أو تقارير الإدارة. لا تدخل التحذيرات في النسخة المطبوعة.
تتحدث حالة الاطلاع والتفعيل من بيانات Supabase الحالية عند تحديث صفحة إدارة الاحتياط وإعادة فتح جدول النشر.
