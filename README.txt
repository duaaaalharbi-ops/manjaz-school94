تحديث الاحتياط اليومي 1.4 — بطاقات الإدارة + التاريخ الهجري

التحديث يجمع في حزمة واحدة:
- قاعدة بيانات الإصدار السادس ومحرك المفاضلة السابق.
- جميع القواعد والاستثناءات المتفق عليها.
- التعديلات الجديدة التالية:

1) جميع التواريخ الظاهرة داخل قسم الاحتياط هجري فقط (أم القرى).
2) بطاقة الإنشاء اليدوي:
   - تحديد جميع الغائبات أولًا.
   - إظهار جميع حصص كل غائبة.
   - قائمة منسدلة لمعلمة التسديد لكل حصة.
   - القوائم تعرض المتاحات فقط وتستبعد الغائبات.
   - لا يسمح بالحفظ قبل تسديد جميع الحصص.
   - فحص جميع التعارضات عند الحفظ، وتحذير إداري مع السماح بالتجاوز.
   - الحفظ اليدوي يعتمد الجدول مباشرة ويظل قابلًا للتعديل الإداري.
3) بطاقة الإنشاء الآلي:
   - نفس محرك الترشيح والاستثناءات والمفاضلة المبرمج سابقًا.
4) بطاقة احتساب المفاضلة:
   - مستقلة للأسبوع الحالي.
   - النصاب، الحصص الأصلية اليوم، احتياط اليوم، احتياط الأسبوع، الأسبوع السابق، التراكمي، نقص الغياب، حالة الاستثناء.
   - تصدير أسبوعي.
   - تصحيح إداري يدوي بسجل مستقل.
5) بطاقة التميز:
   - عدد الحصص المسندة يوميًا وأسبوعيًا.
   - تراكمي.
   - عناوين التفعيل.
   - 3 حصص أو حصتان في يوم واحد تدخلان في التميز حتى دون عنوان تفعيل.
   - الحصة الواحدة لا تدخل في التميز إلا عند تسجيل عنوان التفعيل.
   - تكرار المركز عند التساوي والترتيب الأبجدي.
   - تصدير أسبوعي وتراكمي.
6) Excel يعرض التاريخ الهجري.
7) لا يستخدم Local Storage كمصدر بيانات تشغيلي.
