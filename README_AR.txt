تحديث قسم «ملف التحصيلي» — منصة منجز

الملف المطلوب رفعه:
  tahsili-file.js

الخطوات:
1. افتحي مستودع GitHub الخاص بمنجز.
2. ارفعي tahsili-file.js إلى جذر المستودع عبر Add file > Upload files > Commit changes.
3. افتحي ملف index.html واضغطي Edit.
4. قبل وسم </body>، أو بعد استدعاء talent-links.js، أضيفي السطر التالي:
   <script src="tahsili-file.js?v=1.0"></script>
5. احفظي عبر Commit changes ثم افتحي منصة منجز مجددًا.

بعد ذلك:
- تظهر بطاقة «ملف التحصيلي» بعد «الموهبة» مباشرة في الرئيسية.
- «استعراض» يعرض رابط Google Drive الحالي.
- «إضافة» تفتح نموذج إضافة/تعديل الرابط مباشرة.
- يُخزّن الرابط سحابيًا في records بنوع tahsili_drive_link.
- لا حاجة لإنشاء جدول جديد في قاعدة البيانات.
- لا توجد حقول عنوان/وصف ولا رفع ملفات أو معاينة مضمّنة.
- لم يتم إضافة رابط افتراضي لأن رابط درايف لم يُقدَّم بعد.

ملاحظة: هذا القسم يحاكي صلاحيات «الموهبة» الحالية، ومنها الإضافة/التعديل/الحذف.
