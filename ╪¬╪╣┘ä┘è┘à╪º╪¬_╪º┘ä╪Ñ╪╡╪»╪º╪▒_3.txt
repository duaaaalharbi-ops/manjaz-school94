منجز — الإصدار 3

الصفحة الرئيسية:
1) الممارسات الميدانية
   - أبرز المنجزات: استعراض المنجزات / إضافة منجز

2) النمو المهني
   - الورش التدريبية: استعراض / إضافة / إصدار شهادة حضور ورشة
   - الدروس التطبيقية: استعراض / إضافة / إصدار شهادة حضور
   - نماذج الإنتاج المعرفي القابلة للتطبيق: استعراض / إضافة
   - برامج قيد الإنشاء: استعراض / إضافة

3) الشراكة المجتمعية
   - استعراض الشراكات / إضافة شراكة

4) برامج الهيكل الإداري
   - استعراض البرامج / إضافة برنامج / إصدار شهادة حضور

التصميم:
- عنوان كل قسم خارج البطاقات
- عناوين البطاقات موحدة
- جميع إجراءات استعراض/إضافة/إصدار في أسطر مستقلة
- لا تسطير
- نظام ألوان ووظائف موحد
- عرض جوال عمودي
- لم يتم حذف بيانات أو وظائف الأقسام الأصلية

ارفعي جميع ملفات الحزمة إلى نفس مجلد الموقع واستبدلي النسخ القديمة ثم Commit changes.
