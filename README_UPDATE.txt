بوابة منجز — تحديث الورش التدريبية والدروس التطبيقية
الإصدار: 11.0
التاريخ: 2026-10-05

ما تم تنفيذه:
- توحيد تصميم بطاقات الورش والدروس التطبيقية.
- الإجراءات داخل كل بطاقة فعلية: إصدار الشهادة / تعديل / حذف.
- إصلاح إضافة وتعديل وحذف الورش مع الحفاظ على البيانات الأساسية ومفتاح التخزين الحالي manjaz_workshops_managed_v1.
- إضافة تخزين دائم لإدارة الدروس فوق بيانات MANJAZ_APPLIED_LESSONS باستخدام manjaz_applied_lessons_managed_v1 دون تغيير البيانات الأساسية.
- منع الإضافة المكررة الناتجة عن الضغط المتكرر على الحفظ.
- إزالة ازدواج مصدر إنشاء بطاقات الدروس؛ المصدر الوحيد applied-lessons.js.
- شهادة الورش مبنية على النسخة القديمة المعتمدة، مع رفع التذييل 7px فقط (58px -> 65px).
- شهادة الدروس مستقلة برمجيًا، وتستخدم نفس الهوية والتوزيع وآلية المعاينة والتصدير عالي الجودة.
- الصفحة الرئيسية: الورش والدروس = استعراض + إضافة فقط، ولا يوجد إصدار شهادة في الرئيسية.
- لا يوجد قسم الخدمات الرقمية ولا برامج قيد الإنشاء.
- إصلاح MutationObserver لمنع إعادة الرسم المستمر/الاهتزاز في واجهة الورش.

الملفات الرئيسية المعدلة:
- certificates.js

- index.html

مهم عند الرفع:
- استبدلي الملفات الموجودة بنفس الأسماء.
- لا تمسحي localStorage أو قاعدة البيانات أو ملفات البيانات الحالية.
- اتركي community-sections.js وبقية أصول الصور/الشعارات الحالية على الاستضافة كما هي.
