تحديث قسم الشراكة المجتمعية فقط

ارفعي:
- home-v3.js
- partners-cloud.js

الوظائف:
- Supabase هو مصدر بيانات الشراكة.
- لا يتم إنشاء بيانات شراكة جديدة في Local Storage.
- تُقرأ البيانات المحلية القديمة فقط لترحيلها مرة واحدة، ثم تُحذف النسخة المحلية بعد اكتمال الترحيل بنجاح.
- رفع عدة صور وعدة ملفات.
- الإضافة اللاحقة للمرفقات تراكمية.
- حذف مرفق واحد فقط دون التأثير على البقية.
- استبدال/تعديل مرفق واحد فقط مع إبقاء بقية المرفقات.
- تعديل بيانات بطاقة الشراكة وحذف البطاقة يستمران عبر وظائف الموقع الحالية مع مزامنة Supabase.
- لم يتم تعديل app.js أو شهادات الورش أو الدروس أو CSS أو أي قسم آخر.
