تحديث سحابي لقسم «التكريمات وشهادات الشكر»

ارفعي فقط:
- index.html
- awards-cloud.js

التحديث:
- يجعل Supabase مصدر البيانات الأساسي للقسم.
- لا يحفظ تكريمات جديدة في Local Storage.
- يرحّل أي بيانات قديمة باقية محليًا إلى Supabase عند الإمكان ثم يزيل النسخة المحلية القديمة.
- يسمح بإضافة عدة صور وعدة ملفات إلى البطاقة نفسها.
- يبقي التعديل والحذف والاستعراض بهوية القسم الحالية.
- لا يغيّر app.js أو CSS أو الشهادات أو الدروس أو الورش أو قاعدة Excel.
