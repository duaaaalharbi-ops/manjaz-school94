تحديث موجز بطاقة التكريم فقط.

التغيير الوحيد الوظيفي:
- إضافة حقل «موجز التكريم / شهادة الشكر» في نموذج الإضافة.
- حفظ الموجز داخل نفس سجل award في Supabase.
- عرض الموجز كاملًا داخل البطاقة دون قص.
- السجلات القديمة بلا موجز تستمر بعرض سبب التكريم كما كانت.

لا تغيير في التصميم العام أو التخزين أو المرفقات أو التعديل والحذف أو بقية الأقسام.
