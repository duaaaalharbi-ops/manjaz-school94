قسم التكريمات وشهادات الشكر
- اسم القسم في سطر واحد.
- زرا: استعراض + إضافة.
- زر الإضافة يفتح نموذج الإضافة مباشرة.
- إضافة خيار «شهادة شكر».
- إضافة صور متعددة مفعلة عبر نظام المرفقات الحالي.
- استعراض التفاصيل + تعديل + حذف محفوظة كما هي.
- نفس الهوية البصرية لبقية الأقسام.
- لا تعديل على app.js أو الشهادات أو Excel أو الدروس التطبيقية.
