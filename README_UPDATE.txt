إصلاح حذف المرفقات داخل بطاقات التكريم.

- لا يُحذف أي مرفق إلا عند الضغط على «حذف المرفق» لذلك المرفق تحديدًا.
- الحذف يزيل المرفق المطلوب فقط.
- جميع الصور والملفات الأخرى تبقى كما هي.
- قبل الحذف تُقرأ أحدث نسخة سحابية لحماية مرفقات أضافها مستخدم آخر.
- الإضافة التراكمية متعددة المستخدمين مستمرة كما هي.
- لا تغيير في شكل البطاقة أو بقية الأقسام.
